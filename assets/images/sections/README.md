# Section image specifications

Upload WebP files to this folder using the exact filenames below.

| Section | Filename | Recommended size | Display size | Aspect ratio | Notes |
|---------|----------|------------------|--------------|--------------|-------|
| Home → Engineering Assurance | `home-engineering-assurance.webp` | **1200 × 840 px** | ~600 × 420 px | 10∶7 | Landscape structural / engineering scene; sits in the right column beside the assurance list |
| About → Founding Vision | `about-founding-vision.webp` | **1200 × 1040 px** | ~600 × 520 px | 15∶13 | SIDCO workshop or fabrication facility; badge overlay sits bottom-left |
| Contact → Our Location | `contact-location-map.webp` | **2400 × 760 px** | full width × 380 px | ~3.2∶1 | Wide aerial or street-level photo of SIDCO Sundarapuram area; map pin overlay is centred |

## Format
- **Format:** WebP
- **Quality:** 80–85
- **Colour:** sRGB
- **Safe area:** Keep important detail away from edges (rounded corners and overlays crop slightly)

## Project images
Project case-study photos live in `assets/images/projects/` at **1400 × 480 px** (see filenames `01`–`06`).
