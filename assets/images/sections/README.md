Upload WebP files to this folder using the exact filenames below.

| Section | Filename | Size (current) | Display size | Aspect ratio | Used on |

## Format
- **Format:** WebP
- **Quality:** 80–85
- **Colour:** sRGB
- **Safe area:** Keep important detail away from edges (rounded corners and overlays crop slightly)
